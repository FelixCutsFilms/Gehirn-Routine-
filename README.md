# Gehirn Routine

15-Minuten-Routine zur Gehirnaktivierung als installierbare Web-App (PWA): Bewegung, Lesen (Wikipedia), 4 Denkaufgaben aus 11, Abruf.

- Fortschritt (Stufen, Serie) wird lokal im Browser gespeichert, Export/Import über die Startseite.
- Reine statische Dateien, keine Build-Schritte.
